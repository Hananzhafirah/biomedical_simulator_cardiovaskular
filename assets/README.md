# Optional 3D asset

You may place a glTF binary model here as:

```text
heart.glb
```

The web app will automatically try to load it. If it is absent, the built-in procedural heart is used.

For a Sketchfab model:

1. Confirm the model is downloadable.
2. Confirm the license allows your intended educational use.
3. Export/download as GLB or convert to GLB.
4. Rename the file to `heart.glb`.
5. Complete `ATTRIBUTION.md` with creator, title, source URL, and license.

The current web app pulses the entire imported model for visualization. It does not require special object names or shape keys.
